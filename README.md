# Полотно

Минималистичная доска для текста, свободных линий и связей между мыслями. На белом полотне — три кнопки: линия, настройки текста и отмена. Интерфейс на русском языке, без внешних сервисов и ключей доступа.

## GitHub Pages

Версия для публикации находится в `docs/index.html`. Это один автономный файл, поэтому он работает по вложенному адресу проекта `/1/` без дополнительных ресурсов.

Для включения сайта в репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main** и каталог **/docs**, затем нажмите **Save**. После завершения публикации приложение будет доступно по адресу `https://ushnitskiyigor-blip.github.io/1/`.

После изменения приложения обновите публикуемую версию командой `npm run build:pages` и отправьте изменения, включая `docs/`, в `main`.

## Открыть без установки

Готовый файл `dist/Polotno.html` можно открыть двойным щелчком в браузере. Весь код и оформление находятся внутри одного файла: сервер, Node.js и подключение к интернету для работы доски не нужны.

Чтобы заново собрать этот файл из исходников:

```sh
npm ci
npm run build:standalone
```

Запуск сервера в облачной среде сам по себе не создаёт общедоступную ссылку. Для работы прямо на странице чата интерфейс чата должен поддерживать предпросмотр веб-приложений.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Для сборки: `npm run build`. Для проверки сборки: `npm run preview`.

## Управление

- На пустой доске можно нажать «Начать писать». По умолчанию щелчок выбирает текст, перетаскивание левой кнопкой перемещает его. Двойной щелчок по свободному месту создаёт текст, по существующему — редактирует его. Можно также щёлкнуть по полотну и сразу начать печатать. На сенсорном экране используется двойное касание.
- Enter завершает ввод, Shift+Enter добавляет строку. Esc завершает редактирование.
- Значок линии включает рисование и подсвечивается. Удерживайте левую кнопку и ведите мышь: стабилизатор убирает дрожь и мелкие рывки, сохраняя плавные изгибы. Предпросмотр и сохранённый штрих используют одинаковое сглаживание. Повторное нажатие кнопки или Esc возвращает обычное управление; Alt+L переключает режим. Двойной щелчок или начало печати также сразу переводит из рисования к тексту.
- Проведите линию через заметную часть слова или обведите его — появится обводка. Проведите линию между двумя словами — появятся рамки и тонкая связь, которая следует за перемещением текста. У длинного штриха, проходящего через одно слово, сохраняется гибкий хвост.
- Кнопка A задаёт шрифт, размер, начертание, цвет и форму обводки: прямоугольник, квадрат, овал-капсула с прямыми верхом и низом или без рамки. Настройки меняют выбранные слова и стиль следующего текста.
- Правая кнопка по тексту открывает небольшую панель форматирования: начертание, выравнивание, размер, цвет и удаление.
- Рамка выделения или Shift+щелчок выбирает несколько блоков. Delete/Backspace удаляет выбранное. Стрелки перемещают текст, Shift ускоряет перемещение.
- Выберите фразу и нажмите «Разделить на слова» под ней, чтобы двигать слова отдельно. Выберите несколько блоков и нажмите «Объединить», чтобы собрать их в один текст. Сочетания: Ctrl/⌘+Shift+G — разделить, Ctrl/⌘+G — объединить. Внешние связи сохраняются.
- Щёлкните по связи, чтобы показать три ручки. Средняя меняет изгиб, крайние переносят конец к другому слову. Отпускание конца в пустом месте сохраняет прежнюю связь. Панель рядом позволяет выпрямить или удалить связь; Delete/Backspace тоже удаляет выбранную связь.
- При переносе текста соседние блоки мягко раздвигаются с учётом их обводок. Связи и прикреплённые штрихи следуют за словами.
- Ctrl/⌘+Z отменяет действие, Ctrl/⌘+Shift+Z повторяет. Кнопка со стрелкой также отменяет действие.
- Колесо мыши или Пробел+перетаскивание перемещает полотно. Средняя кнопка мыши также позволяет его перемещать.
- Кнопки внизу справа уменьшают и увеличивают масштаб, возвращают 100 % и показывают всю доску. Ctrl/⌘+колесо или жест двумя пальцами меняет масштаб вокруг указателя. Сочетания: Ctrl/⌘+плюс/минус, Ctrl/⌘+0 — 100 %, Home — показать всё.
- В меню A, в разделе «Доска», кнопка «Сохранить в файл» скачивает `.polotno` с текстом, оформлением, линиями, связями и положением полотна. «Открыть файл» восстанавливает такую доску; открытие можно отменить. Сочетания: Ctrl/⌘+S и Ctrl/⌘+O. Файлы обрабатываются в браузере.

Полотно автоматически сохраняет одну текущую доску в localStorage этого браузера. После перезагрузки восстанавливаются текст, оформление, штрихи, связи и положение полотна. Для нескольких досок, резервных копий и переноса между устройствами используйте файлы `.polotno`. Галереи досок, серверного хранения и совместного редактирования нет; очистка данных браузера удаляет автоматическую копию.

## Проверки

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Модульные тесты проверяют геометрию линий, обводки, раздвижение объектов, разделение и объединение текста, чтение и сохранение досок. Браузерные тесты проверяют ввод, перенос, режим рисования, Esc, редактирование связей, форматирование, отмену, файлы, масштабирование, автономный HTML и мобильную раскладку. Браузерные тесты используют системный Chromium при его наличии; другой путь можно задать переменной `CHROMIUM_PATH`.
